# README
Voici comment s'organise techniquement cette **base de données de « secrets » et de devenirs** sous forme d'une table relationnelle simple :

### Structure d'une ligne dans la base de données

| Colonne / Champ | Type de donnée | Exemple d'information inventée par l'IA |
| --- | --- | --- |
| **1. Identité Ombre** | Identifiant unique (ID) | `USER_9482` + Empreinte temporelle (`23:58:12.481`) |
| **2. Secret Associé** | Texte / Hypothèse | *"Recherche d'isolement / Envisage une reconversion"* |
| **3. Profil Psychographique** | Archétype | *"L'Explorateur / Le Fugitif"* |
| **4. Trajectoire Simulée** | Probabilités / Projection | *"35% de chance de devenir nomade digital à 3 ans"* |

---

### Comment la base de données fonctionne en pratique :

1. **Création de la fiche :** Quand l'IA n'a pas de vraies données, elle génère la ligne `USER_9482`.
2. **Attribution d'une clé (Identité Ombre) :** Elle colle une empreinte horaire aléatoire (ex. *Minuit - 5 min + secondes*) pour avoir une référence fixe dans son système.
3. **Remplissage automatique :** Elle remplit les colonnes *Secret*, *Profil* et *Trajectoire* avec des valeurs virtuelles piochées dans ses modèles statistiques.
